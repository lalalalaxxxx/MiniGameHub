# MiniGameHub

一个面向 iPad 和儿童触摸操作的纯静态小游戏集合。

## 性能维护

全站音频由输入、加载完成和页面生命周期事件同步，不再每 100 毫秒轮询。暂停、结束、后台及真正静止的棋盘停止动画调度，输入后恢复；鱼游动、角色待机、弹道、连消和结算动画继续正常播放。Canvas 静态地图和图稿按尺寸缓存，地图破坏后失效，缓存数量有上限；拖动绘制合并到下一帧，数独和安静书复用已有节点。塔防复用目标位置并减少排序，小鸟匹配只在相关棋盘状态变化时重新扫描；物理步长、游戏规则和音效素材保持不变。

`tests/performance-*.cjs` 检查循环休眠与唤醒、缓存刷新、密集战斗规则一致性、拖动节点复用和音频状态。原有 `tests/extra-performance.cjs`、`tests/match-performance.cjs`、`tests/animation-performance.cjs` 检查复杂场景帧耗时与效果数量；发布仍须运行完整 `npm test`。

可在同一台机器串行测量优化前后的全部 53 款游戏：`node tools/profile_games.cjs --root <代码目录> --out <报告.json>`。脚本默认使用 1024×650 触屏视口、Chrome 4 倍 CPU 降速，记录启动后、暂停或帮助页面、模拟隐藏时的 RAF、绘制、定时器、存储写入和主线程时间。用 `--ids snake,tetris` 可筛选游戏。报告包含采样与插桩开销，适合同条件比较，不代表 iPad 真机帧率；没有暂停按钮的游戏会标为 `idle`，不能将其解释为暂停。

背景缓存另可用 `node tools/profile_extra_cache.cjs --ids fireice,zumapath,slingblocks,tankguard,bombergarden,trafficpark,tripletown,waterworks --out <报告.json>` 做同页面、同状态、同画布尺寸的三轮交替对照。报告分别记录绘制提交和完成栅格化的成本，避免只因绘制调用减少就误判提速；不要与其他浏览器测试同时运行。

| 弹球打砖块 | 成串发射小球，碰撞扣除砖块数字；收集 +1 增加球数，每轮砖块下移，有加速和提前召回 |

统一支持最近三次操作撤销、关卡选择、帮助、重来确认和本地存档。暂停、切后台不会消耗时间；刷新后手动继续。iPad 横屏、竖屏及手机均在一屏内显示主要按钮。单次触摸手势独占输入，第二根手指不会改变正在瞄准或切割的手势。

`casual-core.js` 使用固定 1/120 秒物理步长，存档包含运动中的弹球、钩子、糖果及机关状态。`casual-ui.js` 缓存背景和精灵、限制特效数量、复用控件，暂停后停止动画循环。割绳子的整次划动只记一次操作，可完整撤销。泡泡有弹射拖尾、弹开和重力下落，砖块受击压缩并闪亮，矿工绞盘随重量与加速状态转动，糖果有断绳回弹和吞吃，蜗牛有爬行动作、翻桥和升门动画。通关反馈播放后再展示结算；减少动态效果时去掉装饰位移、震动和粒子。

30 个原创短音效区分泡泡、玻璃砖、金属钩子、金币、绳纤维及木质机关；连续撞击会轻微改变音高，最多同时播放 12 个音效，保持提示清楚且不过响。音效生成可重复，输出带峰值和时长校验。

生成入口、封面和音效：`node tools/build_casual.cjs`、`python tools/generate_casual_audio.py`。生成后必须重新构建 `sw.js`。核心测试验证全部 50 关存在合法通关操作，割绳子及蜗牛全部可得三星；浏览器测试覆盖实际触控通关、下一关、撤销、多指、取消、横竖屏、音频、刷新恢复和多弹球性能。完整离线测试同时覆盖新游戏入口和音效。

## 小鸟爆破（Birzzle 风格）

以用户提供的 [Birzzle 网页重制版](https://birzzle.com/) 和 [经典模式实机视频](https://www.bilibili.com/video/BV1ukdjYyE2B/) 为玩法参考，独立实现规则、Canvas 小鸟美术和合成音效。早期玩法交叉参考：[iPhone AC](https://iphoneac.com/puzzle8.html)、[iPhoroid](https://www.iphoroid.jp/appli/detail/184)。这不是官方移植，速度、分数和奖励数值针对儿童游玩调整。

- 经典：7×10 棋盘，上方或侧边有空位的未锁小鸟可以拖动；三个同色正交相连后有 0.73 秒追加窗口。新鸟从上方定时落下；低于三排数量时从底部补充。整盘满且没有待消组合才结束。
- 破冰：7×9 棋盘，点击任意列从顶部投下一只鸟。相邻消除破冰，冰中包含加时、金蛋和炸弹；清除底部两行以上的冰自动进入下一波并加时。冰块固定，其他小鸟自然下落。
- 潘多拉：120 秒起步，用超能爆破打开宝盒，逐个收集 BIRZZLE 字母，集齐后奖励时间和超能鸟。
- 额外保留无计时练习与两分钟狂热模式；悠闲和经典节奏分别控制自动掉排速度。
- 4 / 5 / 6 / 7 只分别合成周围爆破、向下燃烧及底部爆破、同行同列闪电、全盘黑洞。新合成的鸟留在棋盘，下一次匹配或被其他超能击中才发动。匹配锁鸟先解锁，超能爆破可直接清除。

`bird-core.js` 使用可序列化的分组倒计时。每组独立消除，绘制不锁输入，存档保留尚未结束的追加窗口。`bird-ui.js` 使用固定触摸网格、单 Canvas、缓存小鸟图像与数量受限的羽毛/光圈/光束。页面隐藏会暂停，刷新后需主动继续。旧版存档保留在旧键，新的棋盘结构使用 `childgame.birdblast.v2`。`tools/generate_bird_audio.py` 生成四种原创超能音效，无需依赖第三方素材。

`tests/bird-core.cjs` 验证侧边抓取、追加合成、四种超能连锁、锁鸟、宝盒、破冰投放/换波、计时结束和存档；`tests/bird-games.cjs` 通过浏览器验证连续触控、多指、取消、暂停、恢复、五种模式、横竖屏和 4 倍 CPU 降速下的效果数量及帧耗时。

## 离线与更新

网站仍是静态部署，使用 Service Worker 保存完整版本，不需要后端。首次联网打开大厅，等待“离线已就绪”，全部游戏、图片、音乐和音效就都已保存。之后可以在断网时重新打开大厅或主屏幕图标，并进入此前没有玩过的游戏。首次从未下载过的设备不能离线访问；Safari 清理网站数据或回收存储后，需要重新联网保存，出发前应检查大厅状态。

联网打开、恢复网络、切回页面和每五分钟会检查更新。新版所有文件都通过 SHA-256 校验后，大厅显示“更新”；点击后切换完整版本并刷新。为保护进行中的游戏，更新时需要先关闭其他游戏屋页面。下载失败仍使用旧版本，其他应用的缓存和游戏最高分不会被删除。

`sw.js` 由全部公开资源的内容生成，不能手工修改。修改游戏或素材后，提交和部署前必须运行：

```bash
python tools/build_offline.py
python tools/build_offline.py --check
```

将生成的 `sw.js` 和对应资源一起部署，通过版本目录原子切换上线。服务器对 `/minigames/` 下的响应设置 `Cache-Control: no-cache, must-revalidate`，避免浏览器的 HTTP 缓存挡住版本检查；离线副本由 Service Worker 独立管理。离线功能需要 HTTPS 或 localhost。

离线与升级回归测试：

```bash
npm ci
npx playwright install chromium webkit
npm test
```

设置环境变量 `TEST_BROWSER=webkit` 可用 WebKit 运行同一组测试。测试覆盖全量离线访问和声音解码、旧版本号书签、多页面升级保护、失败回滚、缓存丢失后的修复。

Windows 版 Playwright WebKit 不提供 Web Audio API，因此该环境验证离线音频字节完整性；实际音频解码由 Chromium 测试覆盖，实体 iPad 的系统存储行为仍需实机验证。

## 添加游戏

1. 在 `games/` 下创建独立目录，并提供 `index.html`。
2. 为游戏添加 `cover.svg`。
3. 在 `games/manifest.json` 中登记游戏信息。

当前包含小小数独、软软生活安静书、贪吃蛇、2048、俄罗斯方块、打地鼠、星星大战、彩虹赛车和水果合成。

| 游戏 | 主要玩法 |
| --- | --- |
| 小小水管工 | 旋转管道、观察水流，进阶连接两处分支花园 |

`tests/learning.cjs` 验证随机关卡规则，并通过真实界面逐一完成十款游戏的全部三档难度，覆盖刷新续玩、撤销、错误反馈、换关确认、多指与取消拖拽、录制回放和横竖屏。可设置 `LEARNING_GAME=pipes` 等游戏 ID 单独调试；完整发布必须清除该筛选，运行全套测试。

## 小小数独

面向小学低年级，提供 4×4 入门、6×6 练习和挑战。4×4 使用 2×2 小宫，6×6 使用 2×3 小宫；每题只有一个答案，均能通过唯一候选数或宫/行/列内唯一位置逐步解出。支持数字与图形辅助、草稿、重复提示、检查、先解释再填入的提示、撤销、换题确认、键盘操作和本地自动存档。不计时、不扣分，仅播放轻柔操作音效。全部资源支持离线使用。

`tests/sudoku.cjs` 抽查三档共 300 道随机题的合法性、唯一解及无需猜测的解题路径，并验证触摸输入、草稿、提示、检查、撤销、切换难度、存档、完成反馈和响应式布局。

## 软软生活安静书

提供植物守卫、萌系精灵、冰雪公主三套原创主题，共六个角色。衣柜支持换装搭配，点衣物直接穿上，也可以拖到角色身上；同类衣物自动替换，连衣裙替换整套上下装。餐厅支持摆盘和喂食；小屋支持摆放玩具、坐卧、盖被子和关灯。其他贴纸可拖放，或先点贴纸再点场景。支持撤销、收回、清空确认、三个场景示例，并自动保存到当前浏览器。声音为轻柔操作音效，没有循环背景音乐。全部美术为本地 SVG，无外部素材依赖。

新游戏一并进入全站离线缓存。`tests/quietbook.cjs` 遍历六个角色的全部 36 件衣物，检查替换、默认衣物隐藏、移除、撤销、发型与表情；逐件检查全部餐具、食物、玩具、摆件和被子，并验证食物三口吃完。还覆盖点选及拖动换装、键盘操作、无效放置、多指拖动、取消、姿势、灯光、清空确认、声音开关、存档及旧存档迁移、横竖屏布局。配合 `tests/offline.cjs` 检查全站离线和安全更新。

## 游戏声音

七款游戏各有一段复古风格循环配乐，配有十二种通用音效和七种游戏专属音效，素材位于 `assets/audio/`。音乐与音效由 `assets/js/audio.js` 统一管理，不依赖外部音频服务。

方块采用公版民谣《货郎》（Korobeiniki）的简化电子编配；贪吃蛇采用掌机音色；飞机、赛车采用街机节奏；2048、打地鼠和水果合成采用较稀疏的拨弦旋律。发射是短促激光音，命中是爆破音，打地鼠是敲击音，水果合成是气泡音。

首次触摸或按键后才播放，符合 Safari 的自动播放限制。游戏中的声音按钮同时控制音乐和音效，并记住静音设置；暂停、进入后台或离开页面时停音，游戏结束时停止配乐并播放结束音效。

音频会提前加载；浏览器尚未允许播放时显示“开启声音”，点击一次即可尝试启动，加载失败时可重试。背景音乐保持低音量，操作音效播放期间还会自动降低音乐音量，结束后恢复。

音频由项目内的音符和合成器生成；除《货郎》公版旋律外均为原创，不是官方游戏原声，也未使用商业游戏录音或采样。重新生成素材：

```bash
python -m pip install numpy imageio-ffmpeg
python tools/generate_audio.py
```
