# MiniGameHub

一个面向 iPad 和儿童触摸操作的纯静态小游戏集合。

## 本地运行

```bash
python -m http.server 8934
```

打开 `http://127.0.0.1:8934/`。

## 离线与更新

网站仍是静态部署，使用 Service Worker 保存完整版本，不需要后端。首次联网打开大厅，等待“离线已就绪”，全部游戏、图片、音乐和音效就都已保存。之后可以在断网时重新打开大厅或主屏幕图标，并进入此前没有玩过的游戏。首次从未下载过的设备不能离线访问；Safari 清理网站数据或回收存储后，需要重新联网保存，出发前应检查大厅状态。

联网打开、恢复网络、切回页面和每五分钟会检查更新。新版所有文件都通过 SHA-256 校验后，大厅显示“更新”；点击后切换完整版本并刷新。为保护进行中的游戏，更新时需要先关闭其他游戏屋页面。下载失败仍使用旧版本，其他应用的缓存和游戏最高分不会被删除。

`sw.js` 由全部公开资源的内容生成，不能手工修改。修改游戏或素材后，提交和部署前必须运行：

```bash
python tools/build_offline.py
python tools/build_offline.py --check
```

将生成的 `sw.js` 和对应资源一起部署，通过版本目录原子切换上线。服务器对 `/minigames/` 下的响应设置 `Cache-Control: no-cache, must-revalidate`，避免浏览器的 HTTP 缓存挡住版本检查；离线副本由 Service Worker 独立管理。离线功能需要 HTTPS 或 localhost。

离线与升级回归测试：

```bash
npm ci
npx playwright install chromium webkit
npm test
```

设置环境变量 `TEST_BROWSER=webkit` 可用 WebKit 运行同一组测试。测试覆盖全量离线访问和声音解码、旧版本号书签、多页面升级保护、失败回滚、缓存丢失后的修复。

Windows 版 Playwright WebKit 不提供 Web Audio API，因此该环境验证离线音频字节完整性；实际音频解码由 Chromium 测试覆盖，实体 iPad 的系统存储行为仍需实机验证。

## 添加游戏

1. 在 `games/` 下创建独立目录，并提供 `index.html`。
2. 为游戏添加 `cover.svg`。
3. 在 `games/manifest.json` 中登记游戏信息。

当前包含小小数独、软软生活安静书、贪吃蛇、2048、俄罗斯方块、打地鼠、星星大战、彩虹赛车和水果合成。

另有十款面向 5～8 岁儿童的学习小游戏，均提供三档难度、撤销、换关确认、本地进度保存和完整离线资源，总计 19 款游戏：

| 游戏 | 主要玩法 |
| --- | --- |
| 小小水管工 | 旋转管道、观察水流，进阶连接两处分支花园 |
| 图形拼拼乐 | 七块七巧板，45° 旋转，拖放或点选拼出三个图案 |
| 小小超市 | 按清单买齐数量，凑硬币付款，计算找零 |
| 小动物编程 | 前进、原地转向、连续前进，执行路线并寻找钥匙 |
| 便当小厨房 | 按食物分类、数量及颜色条件自由搭配 |
| 影子侦探 | 看影子、观察局部、读文字线索，每轮六题 |
| 规律小火车 | AB、三项重复规律，以及等差数字排列 |
| 记忆翻翻牌 | 同图配对、动物与食物、数字与点数配对 |
| 桥梁小工程师 | 有限材料搭桥、检查连续桥面和支撑，再让小车试走 |
| 节奏小乐队 | 顺序模仿、自由演奏、15 秒以内的敲击录制与回放 |

桥梁采用明确的简化支撑规则，不是工程物理模拟。节奏模仿先练习乐器顺序，不严格考核节拍速度；自由录制保存的是本地敲击时间与乐器编号，不调用麦克风、不上传音频。声音以低音量操作反馈为主，没有循环背景音乐。

`assets/js/learning-core.js` 是可独立验证的关卡规则；`assets/js/learning-ui.js` 统一处理页面、撤销、存档和生命周期，各游戏的 `game.js` 实现独立玩法。`tools/build_learning_pages.py` 生成入口页和封面，重新生成后仍需运行离线构建工具。

`tests/learning.cjs` 验证随机关卡规则，并通过真实界面逐一完成十款游戏的全部三档难度，覆盖刷新续玩、撤销、错误反馈、换关确认、多指与取消拖拽、录制回放和横竖屏。可设置 `LEARNING_GAME=pipes` 等游戏 ID 单独调试；完整发布必须清除该筛选，运行全套测试。

## 小小数独

面向小学低年级，提供 4×4 入门、6×6 练习和挑战。4×4 使用 2×2 小宫，6×6 使用 2×3 小宫；每题只有一个答案，均能通过唯一候选数或宫/行/列内唯一位置逐步解出。支持数字与图形辅助、草稿、重复提示、检查、先解释再填入的提示、撤销、换题确认、键盘操作和本地自动存档。不计时、不扣分，仅播放轻柔操作音效。全部资源支持离线使用。

`tests/sudoku.cjs` 抽查三档共 300 道随机题的合法性、唯一解及无需猜测的解题路径，并验证触摸输入、草稿、提示、检查、撤销、切换难度、存档、完成反馈和响应式布局。

## 软软生活安静书

提供植物守卫、萌系精灵、冰雪公主三套原创主题，共六个角色。衣柜支持换装搭配，点衣物直接穿上，也可以拖到角色身上；同类衣物自动替换，连衣裙替换整套上下装。餐厅支持摆盘和喂食；小屋支持摆放玩具、坐卧、盖被子和关灯。其他贴纸可拖放，或先点贴纸再点场景。支持撤销、收回、清空确认、三个场景示例，并自动保存到当前浏览器。声音为轻柔操作音效，没有循环背景音乐。全部美术为本地 SVG，无外部素材依赖。

新游戏一并进入全站离线缓存。`tests/quietbook.cjs` 遍历六个角色的全部 36 件衣物，检查替换、默认衣物隐藏、移除、撤销、发型与表情；逐件检查全部餐具、食物、玩具、摆件和被子，并验证食物三口吃完。还覆盖点选及拖动换装、键盘操作、无效放置、多指拖动、取消、姿势、灯光、清空确认、声音开关、存档及旧存档迁移、横竖屏布局。配合 `tests/offline.cjs` 检查全站离线和安全更新。

## 游戏声音

七款游戏各有一段复古风格循环配乐，配有十二种通用音效和七种游戏专属音效，素材位于 `assets/audio/`。音乐与音效由 `assets/js/audio.js` 统一管理，不依赖外部音频服务。

方块采用公版民谣《货郎》（Korobeiniki）的简化电子编配；贪吃蛇采用掌机音色；飞机、赛车采用街机节奏；2048、打地鼠和水果合成采用较稀疏的拨弦旋律。发射是短促激光音，命中是爆破音，打地鼠是敲击音，水果合成是气泡音。

首次触摸或按键后才播放，符合 Safari 的自动播放限制。游戏中的声音按钮同时控制音乐和音效，并记住静音设置；暂停、进入后台或离开页面时停音，游戏结束时停止配乐并播放结束音效。

音频会提前加载；浏览器尚未允许播放时显示“开启声音”，点击一次即可尝试启动，加载失败时可重试。背景音乐保持低音量，操作音效播放期间还会自动降低音乐音量，结束后恢复。

音频由项目内的音符和合成器生成；除《货郎》公版旋律外均为原创，不是官方游戏原声，也未使用商业游戏录音或采样。重新生成素材：

```bash
python -m pip install numpy imageio-ffmpeg
python tools/generate_audio.py
```
